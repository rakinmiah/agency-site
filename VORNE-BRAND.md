# VORNE — the case, logged 2026-07-24

## The word
German everyday adverb: AT THE FRONT. "Ganz vorne" = in the lead; "vorne liegen" = leading
(races, polls, league tables); football's "vorne" = up front, where goals come from.
Every native use means: the position that wins.

## Bloodline
Old High German *forna* ← same Proto-Germanic root as English FORE / BEFORE / FOREFRONT /
FOREMOST — and FIRST (OE *fyrst* = "fore-most"). Vorne is the old cousin of "first".
