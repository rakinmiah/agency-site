two o's, one continuous path
Set in Jost — a geometric face whose lowercase o is a true circle, which is the only way two o's can resolve into a single figure-eight without looking like a bodge. The infinity is not a slogan about connection: it is the weft's actual path, one thread turning back on itself pass after pass until there is cloth.
